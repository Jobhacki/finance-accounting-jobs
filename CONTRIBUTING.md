# Contributing to the Finance and accounting jobs list

Help finance and accounting professionals find openings that fit their work. Share the employer's posting so readers can check duties and qualifications.

## What belongs in this list

Accounting, audit, tax, financial analysis, payroll, and finance operations roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and the accounting or finance focus.

[Open the Add a job form](https://github.com/Jobhacki/finance-accounting-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the role title, employer, link, and whether the finance or accounting posting is missing or filled.

[Open the Report a dead link form](https://github.com/Jobhacki/finance-accounting-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
